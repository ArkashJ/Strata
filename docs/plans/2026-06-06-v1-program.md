# Strata → v1.0 program (2026-06-06)

The sequenced plan to take Strata from "looks built, doesn't feel usable" to a tool an
operator would actually use. Full architecture in
[`../architecture/ARCHITECTURE.md`](../architecture/ARCHITECTURE.md); chart/dashboard detail
in [`../architecture/charts-and-dashboards.md`](../architecture/charts-and-dashboards.md);
question bank in [`../questions/README.md`](../questions/README.md).

## Why (the diagnosis, verified live)

A headed walkthrough + 6-agent codebase synthesis confirmed concrete gaps:
- **Trust collapses on first contact** — homepage/demo TAMs render under a "SHA-256 pinned ·
  reproducible" claim while every demo primitive carries a **fake snapshot** `d3d3…d3` and
  modeled inputs cite the non-resolvable `strata.internal`. (Seen on `/tam/<hash>/report`.)
- **Export is broken** — "Download PDF" = `window.print()` on the interactive app shell;
  markdown omits sources; revoke race.
- **CRM is faked** — `/bank` "My Primitives" is portfolio companies; `tam_outputs`/
  `audit_events` have no `org_id`; Clerk is frontend-only.
- **No live tree, no dashboards; charts aren't analyst-grade**; 2 dead chart components.
- **10 connectors show empty** (mostly missing manifest entries); a DB-path quarantine bug
  could let community data feed TAMs.

## Decisions (owner)

First slice = **live steerable TAM tree + real per-user workspace**, on **full server-backed
multi-tenant** persistence (Clerk→backend), with the question bank **fully curated YAML**,
TAM/market-focused. Never merge to `main` — stacked, reviewed PRs.

## Design governance

All UI work obeys "The Sourced Ledger" + the impeccable contract (see ARCHITECTURE.md anchor):
identity-preservation (upgrade, don't rewrite), **a colour means one thing** (tier ramp =
provenance, cool family = lens), tabular-mono numerals, source-footnote chart frames,
reduced-motion + focus + WCAG 2.2 AA, no SaaS-slop bans.
