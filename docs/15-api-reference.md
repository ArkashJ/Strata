# Strata API Reference

**Version:** 0.11.0
**Base URL:** `http://localhost:8000` (dev) · Railway production URL per deploy config
**Interactive docs:** `/docs` (Swagger UI) · `/redoc` (ReDoc) · `/openapi.json` (raw spec)

This document is the human-readable companion to the machine-precise
`/openapi.json`. The live spec is auto-generated by FastAPI from the route
definitions, so it is always authoritative for exact request/response schemas;
this reference exists to give each endpoint a purpose, its auth and error
behaviour, and the shape of its payloads at a glance.

---

## Keeping the spec + clients in sync

The spec is emitted live at `/openapi.json`. A committed snapshot lives at
`backend/openapi.json` so CI and the frontend can consume it without booting the
server.

```bash
# backend/ — regenerate the committed snapshot after any route/schema change
uv run python scripts/export_openapi.py
uv run python scripts/export_openapi.py --check   # CI: fail if snapshot is stale

# web/ — regenerate the typed client (web/src/lib/api-schema.d.ts)
bun run gen:api        # fetches /openapi.json from a running backend on :8000
bun run gen:api:file   # reads the committed ../backend/openapi.json (no server needed)
```

## Authentication

Requests authenticate with an **`X-API-Key`** header. This is declared in the
OpenAPI spec as an `APIKeyHeader` security scheme, so `/docs` shows an
**Authorize** button and protected operations are marked secured.

| Mode | Behaviour |
|---|---|
| No header, `require_auth=false` (dev default) | Runs as an anonymous `public` principal — the curated read API stays open locally. |
| No header, `require_auth=true` (prod) | `401` — missing API key. |
| Present but unknown key | Always `401` (a failed auth attempt, even in dev). |
| Valid key | Resolves to a `Principal{org_id}` used for rate-limiting, metering, and Postgres RLS. |

**Endpoints that always require a non-anonymous principal** (reject `public`
even in dev): all `/integrations/*`, `GET /contributions`. Endpoints that accept
the principal but tolerate anonymous in dev: `POST /build/recompute`,
`POST /build/{slug}/promote`, `POST /resolve`, `POST /contribute`, `GET /audit`,
`GET /usage`.

## Error model

Every error response is FastAPI's standard envelope:

```json
{ "detail": "human-readable reason" }
```

Common status codes used across the API:

| Code | Meaning |
|---|---|
| `400` | Malformed input (e.g. invalid OAuth callback state). |
| `401` | Missing or invalid API key. |
| `404` | Named record (concept / primitive / framework / signal / TAM / provider) not found. |
| `409` | Conflicting state (e.g. provider not connected on sync). |
| `422` | Semantic validation failure (e.g. override unit mismatch, unsatisfiable framework inputs). FastAPI also returns 422 for request-body validation. |
| `429` | Rate limit exceeded — honour the `Retry-After` header. |
| `502` | Upstream dependency failed (e.g. OAuth token exchange). |

Per-endpoint error responses are declared in the spec's `responses` object, so
they appear in `/docs` and in the generated TypeScript client.

## Rate limiting

LLM-touching and write routes (`POST /resolve`, `POST /build/recompute`,
`POST /build/{slug}/promote`, `POST /contribute`) are token-bucket rate-limited
per `org_id`. Exhaustion returns `429` with a `Retry-After` header.

### `build`

| Method | Path | Summary | Auth | Errors |
|---|---|---|---|---|
| GET | `/build/{concept_slug}` | Evaluate a concept through all applicable framework variants → `TAMOutput` scenario tree. | — | `422` |
| POST | `/build/recompute` | Recompute a TAM with what-if overrides / primitive swaps / pinned scope. | principal | `401·404·422·429` |
| GET | `/build/{concept_slug}/trajectory` | TAM-over-time series derived from primitive `as_of` dates. | — | `422` |
| GET | `/build/{concept_slug}/sensitivity` | Per-input ±`pct` swing on the TAM (feeds the tornado chart). | — | `404` |
| POST | `/build/{concept_slug}/promote` | Build + promote a TAM (appears in `/browse` + sitemap). | principal | `401·422·429` |
| GET | `/browse` | List promoted TAMs. | — | — |
| GET | `/tam/{state_hash}` | Retrieve a frozen, content-addressed TAM by state hash. | — | `404` |

`POST /build/recompute` body — `RecomputeRequest`:

```json
{
  "concept_slug": "ai-code-review",
  "framework_assumptions": { "cost-efficiency-v1": { "persona_count": "us-software-devs-bls-2023" } },
  "primitive_overrides": { "copilot-seat-cost-2023": { "value": 5000, "unit": { "kind": "flow", "dimension": "currency", "denominator": "year", "currency": "USD", "basis": "nominal" } } },
  "scope": null
}
```

`scope` is the user-pinned `MarketScope` (sub-project 1.5); when non-empty it
overrides the concept's declared scope for the scope guard, and folds into the
resulting `state_hash` (a different pinned market is a different build).
`GET /build/{slug}/sensitivity` takes a `pct` query param (default `0.2` =
±20%).

`TAMOutput` (returned by `/build/*`, `/browse`, `/tam/{hash}`) — the load-bearing
fields:

| Field | Type | Description |
|---|---|---|
| `state_hash` | string | SHA256 of the canonical scenario payload — the permanent URL key. |
| `target.concept_slug` / `.concept_name` | string | Concept that was sized. |
| `scenarios[]` | array | One `Scenario` per satisfiable framework variant. |
| `scenarios[].value` | number | TAM value in the framework's output unit. |
| `scenarios[].lens` / `.framework` | string | Lens applied · framework slug used. |
| `scenarios[].inputs_used[]` | array | Primitives consumed (`role_name`, `value`, `primitive_slug`, `source_url`). |
| `scenarios[].banners[]` | array | Data-quality flags (see `BannerKind`). |
| `independence_score` | number | 0–1; fraction of distinct method families across scenarios. |
| `method_families_used[]` | array | Method families present. |
| `convergence` | object \| null | Agreement cross-check when ≥2 independent method families size the concept. |
| `scope_report` | object \| null | Declared-vs-actual scope classification (derived; not in the hash). |
| `is_promoted` | bool | Whether this TAM appears in `/browse`. |

## MCP server (`/mcp`)

A read-only **Strata MCP server** is mounted as a sub-application at `/mcp`
(streamable HTTP transport). Because it is a mounted ASGI sub-app, **its tools do
not appear in this REST `/openapi.json`** — it speaks the MCP protocol, not REST.
It exposes 12 tools (`search_concepts`, `get_primitive`, `list_frameworks`,
`size_tam`, `resolve_market`, `list_primitives`, `build_tam`, `list_connectors`,
`get_connector_data`, plus the portfolio write tools). Every payload carries
`source_url` + `tier` + `snapshot_sha256`. See `backend/src/strata/mcp/` and the
`/agents` page for connect snippets.

## SSE wire contract (`POST /resolve`)

The backend runs the 4-step resolver pipeline in a thread and pushes events as
milestones are reached. Each event is:

```
event: <event_type>
data: <JSON payload>

```

### Event sequence

```
Client                              Server (pipeline thread)
  │   POST /resolve {"query": "..."}    │
  │─────────────────────────────────────►│
  │   event: parsing                    │  parse intent + primitives needed
  │◄────────────────────────────────────│
  │   event: searching (x N)            │  Exa search per primitive
  │◄────────────────────────────────────│
  │   event: framework_selected         │  lens resolved
  │◄────────────────────────────────────│
  │   event: evaluating                 │  multiplying inputs
  │◄────────────────────────────────────│
  │   event: result                     │  TAM value + primitives + sources
  │◄────────────────────────────────────│
  │   event: done                       │  stream closed
  │◄────────────────────────────────────│
  │   (on any failure) event: error → done
```

### Event payloads

**`parsing`** — `{ "query": "...", "model": "claude-sonnet-4-6" }`
**`searching`** (one per primitive) — `{ "primitive_name": "persona_count", "role": "persona_count" }`
**`framework_selected`** — `{ "framework": "cost_efficiency", "lens": "cost_efficiency" }`
**`evaluating`** — `{ "inputs": [ { "slug": "persona_count", "value": 4650000, "unit": {...} } ] }`

**`result`**

```json
{
  "tam_usd": 18600000000,
  "scenarios": [{ "label": "point", "value": 18600000000 }],
  "sources": [{ "url": "https://bls.gov/...", "tier": "regulator" }],
  "concept_name": "AI-assisted code review tooling",
  "formatted_tam": "$18.6B",
  "lens": "cost_efficiency",
  "framework_name": "Cost Efficiency",
  "independence_score": 0.0,
  "primitives_used": [],
  "banner": "synthesized via fallback — not in data bank, do not cite without manual verification"
}
```

**`error`** — `{ "message": "Could not find enough market data for this query.", "step": "search" }`
**`done`** — `{}`

> The pipeline runs in step-4 fallback mode for HTTP clients (registry-first
> steps 1–3 are attempted first; the `banner` says "synthesized via fallback" for
> novel queries not yet in the data bank). Use `strata promote <slug>` to graduate
> a synthesized primitive into the committed data bank.

## Shared schemas

### Unit

```json
{ "kind": "flow", "dimension": "currency", "denominator": "year", "currency": "USD", "basis": "nominal" }
```

| Field | Allowed values |
|---|---|
| `kind` | `stock` · `flow` · `intensive` · `dimensionless` |
| `dimension` | `currency` · `people` · `organizations` · `percent` · `units` |
| `denominator` | `year` · `month` · `quarter` (only on `flow`) |
| `currency` | ISO 4217 code, e.g. `USD` |
| `basis` | `nominal` · `real` |

### BannerKind

Flags that surface on scenario outputs and become footnotes in exports:

| Value | Meaning |
|---|---|
| `synthetic` | LLM-projected value, not a sourced figure. |
| `modeled` | Community-modeled multiplier. |
| `subsidy` | Includes a government subsidy component. |
| `regulated` | Price or access is regulated. |
| `dark-estimate` | Sparse or indirect sourcing. |
| `analyst-paraphrase` | Paraphrased from an analyst report; verify against full text. |
| `user_override` | A what-if value the user set — never persisted as a primitive (Q20). |

### Six TAM lenses

| Lens | Math shape | Example |
|---|---|---|
| `cost_efficiency` | persona × cost | Copilot, Glean |
| `revenue_generation` | segment × spend | Brex, Rippling |
| `latent_demand` | population × adoption × WTP | Uber |
| `platform_throughput` | volume × take_rate | Stripe, Visa |
| `bundle_consolidation` | total_spend × consolidation | Notion, Linear |
| `productivity_uplift` | personas × value_split | Cursor |
