# Strata v0.2 — Backend Implementation Spec

> Builds on `docs/07-data-layer-brainstorm.md`, `docs/08-product-surface-brainstorm.md`,
> `docs/09-expert-layer-brainstorm.md`. This is the **executable** plan that turns
> the locked schema + UX decisions into a running backend that exercises the full
> schema against the P&C doc-gen verification scenario.

## Status

**Phase:** v0.2 implementation **IN PROGRESS.**
**Scope:** Backend-only. Schemas + validator + YAML loader + framework evaluator +
independence scorer + FastAPI read-only routes + content-hash URL minter +
P&C doc-gen seed data + e2e tests.
**Out of scope (defer to v0.3+):** Frontend (graph renderer), LLM query parser,
search index, semantic embeddings, Postgres mirror, auth, contribution flow.

---

## Stack (locked)

| Layer        | Choice                                                    |
| ------------ | --------------------------------------------------------- |
| Language     | Python 3.12                                               |
| Pkg manager  | **uv** (`uv sync --extra dev`, `uv run …`)                |
| Types        | **Pydantic v2** (records) + **pyright strict** (codebase) |
| HTTP         | **FastAPI** (auto-OpenAPI)                                |
| CLI          | **Typer**                                                 |
| Lint/format  | **ruff** (lint + format)                                  |
| Test         | **pytest** + httpx for FastAPI client                     |
| Storage      | YAML files in `data/` — no DB at v0.2                     |
| Hashing      | stdlib `hashlib.sha256` over canonicalized JSON           |

## Conventions

- **Strict typing.** `pyright --strict` must pass with zero errors before commit.
  Don't use `Any`; prefer `object` + isinstance narrowing if you must.
- **No silent failures.** Validators raise structured errors; the API translates
  to HTTP 4xx/5xx with the validation reason in the body. Per CLAUDE.md spirit,
  don't swallow exceptions.
- **YAML keys are snake_case** matching the Pydantic field names verbatim.
- **Slugs are kebab-case**, globally unique per record type, stable forever.
- **Schemas declare `schema_version: 1`.** Bump only on breaking change.
- **Tests follow TDD per task:** write a failing test, implement minimum to pass,
  commit. Each task has a "verify" command (pytest + pyright clean).
- **Commit cadence:** one task = one commit. Use the existing CHANGELOG `[Unreleased]`
  section; the user (or maintainer) cuts versioned sections at release.

## Tasks (numbered to match the live task list)

### Task 9 — Core types: Unit + Geo + Source + tier enum

Pydantic models for the foundation types every record depends on.

**Files:**
- Create `src/strata/models/unit.py` — `Unit` model per Q4: `kind` (stock/flow/intensive/dimensionless) · `dimension` (people/currency/transactions/events/percent/tokens/impressions) · `denominator` (optional, e.g. per-year, per-seat) · `currency` (USD/EUR/ETH/BTC/...) · `basis` (always `nominal` at storage).
- Create `src/strata/models/geo.py` — `Geo` model per Q8: `level` (country/subnational/supranational/global) · `codes` (list of ISO 3166-2) · `aggregate` (optional named slug) · `aggregation_rule` (union/sum/allocated_by:slug). Plus `geo_perspective` enum (`supply | demand | mixed | unknown`).
- Create `src/strata/models/source.py` — `Source` model: `slug` · `tier` enum (Q37: `first_party | regulator | aggregator | analyst | community | onchain | prediction_market | community_modeled`) · `url` · `accessed` · `snapshot_sha256`.

**Verify:** `uv run pyright src/strata/models/ && uv run pytest tests/models/test_unit.py tests/models/test_geo.py tests/models/test_source.py`

### Task 10 — Entity models: Concept, Primitive, Composite, Framework, Annotation

Pydantic models for the four primary record types + annotation.

**Files:**
- Create `src/strata/models/primitive.py` — `AtomicPrimitive` and `CompositePrimitive`. Atomic carries `source`, `value`, `unit`, `as_of`, `geo`, `geo_perspective`, `distribution_shape` (Q31), `delivery_mode` (Q32), `uncertainty.range` + `basis`, `derives_from` (Q7), `expiry` (Q20 — required for synthetic). Composite carries `inputs: [atomic_slug]` + `set_operation` (Q3: union/intersection/filter/restrict_by_tag).
- Create `src/strata/models/framework.py` — `Framework` + nested `FrameworkInput` + `FrameworkVariant`. Captures `method_family` (Q7), `inputs[].role` (Q6: base_value/growth_index/regime_modifier/conditional_adjustment), `applicable_to` + `not_applicable_to` (Q16), `requires_clearance` (Q36), `expansion_stage_parameter` (Q22), `horizon_class` (Q6).
- Create `src/strata/models/concept.py` — `Concept` (default), `MarketplaceConcept` (Q19 — adds demand_side/supply_side/gmv/take_rate), `CompanyConcept` (Q21 — adds mandatory `segments[]`). `competing_concepts: [slug]` field for sibling-narrow-test (Q10b).
- Create `src/strata/models/annotation.py` — `Annotation` per E3: `target_slug` · `target_type` enum · `author` · `created_at` · `body` (markdown) · `kind_tag` enum · `coi_disclosure` (optional).

**Verify:** `uv run pyright src/strata/models/ && uv run pytest tests/models/`

### Task 11 — TAMOutput + scenario tree

**Files:**
- Create `src/strata/models/tam.py` — `TAMOutput` + `Scenario` + `InputUsed`. Output records: `target` (concept/geo/time/expansion_stage), `scenarios[]` (per Q1), `method_families_used[]`, `independence_score`, `uses_synthetic_primitives`, `uses_modeled_composites`. Each scenario carries `inputs_used[]` with `snapshot_sha256` per input (Q5 content-hash pinning).

**Verify:** model round-trips through Pydantic, content-hash field validates as 64-char hex.

### Task 12 — YAML loader + slug registry

**Files:**
- Create `src/strata/loader.py` — glob `data/**/*.yaml`, parse YAML, dispatch on `kind` field to the right Pydantic model (`atomic_primitive`, `composite_primitive`, `framework`, `concept`, `marketplace_concept`, `company_concept`, `annotation`, `tam_output`).
- Create `src/strata/registry.py` — in-memory `Registry` dataclass keyed by `(record_type, slug)`. Methods: `get(record_type, slug)`, `iter_kind(record_type)`, `resolve_concept_measurements(concept)` returning the linked AtomicPrimitive records.

**Verify:** smoke-load a small fixture in `tests/loader/test_loader.py`. Assert all slugs unique within type and that broken cross-refs raise.

### Task 13 — Validator pipeline (layers 1-3)

**Files:**
- Create `src/strata/validator/structural.py` — re-runs Pydantic; collects errors with file path + line.
- Create `src/strata/validator/semantic.py` — checks: `unit.currency` set iff `unit.dimension == currency|tokens`; `as_of` in past; `snapshot_sha256` is 64-char hex; synthetic primitives have `expiry` set; sig-fig sanity (no `1.23456789e9` for human counts).
- Create `src/strata/validator/cross_record.py` — checks: every concept measurement points at an existing AtomicPrimitive; `competing_concepts` references are symmetric; framework `applicable_to` slugs exist in taxonomy; annotation `target_slug` exists.
- Wire `strata validate <path>` in `cli.py`.

**Verify:** A fixture with an intentionally broken record produces a structured error per layer.

### Task 14 — Content-hash URL minter

**Files:**
- Create `src/strata/hashing.py` — `mint_build_hash(state: BuildState) -> str` returning sha256 hex. `BuildState` is a Pydantic model containing `target_concept_slug`, `geo_filter`, `time_filter`, `constraint_set`, `frameworks_selected`, `framework_assumptions`, `primitive_pins {slug: snapshot_sha256}` (per U6 spec). Canonicalize via `json.dumps(model_dump(mode="json"), sort_keys=True, separators=(",", ":"))` before hashing.
- Wire `strata mint <state.json>` in `cli.py`.

**Verify:** Same state → same hash (round-trip). Reordered keys → same hash. One field change → different hash.

### Task 15 — Framework evaluator + scenario tree

**Files:**
- Create `src/strata/evaluator/expression.py` — safe AST-walked arithmetic evaluator (`+`, `-`, `*`, `/`, parens, identifiers). No eval/exec. Identifiers resolve from a bindings dict.
- Create `src/strata/evaluator/tree.py` — `evaluate(framework, bindings, registry) -> list[Scenario]`. For each definitional choice (narrow/broad/etc.), execute the formula, build a `Scenario` with `inputs_used` carrying the resolved primitive's snapshot hash. If the framework's `expansion_stage_parameter` is true, emit a scenario per stage.

**Verify:** Run the P&C bottoms-up framework against fixture bindings; assert the computed value matches the docs/04 worked example ($47M point estimate).

### Task 16 — Independence scorer + concept disagreement

**Files:**
- Create `src/strata/scoring/independence.py` — `score(scenarios) -> float in [0, 1]`. Inputs: scenarios' `method_families_used` + `derives_from` lineage. Penalty for shared method-family or shared upstream source. Surface a list of method-family-conflict warnings.
- Create `src/strata/scoring/disagreement.py` — `summarise(concept, registry) -> ConceptDisagreement` returning the range bar (min/max + each measurement's value/tier), used by `/c/{slug}` response.

**Verify:** A 3-framework triangulation with all-different method families scores high; same-family pair drops score below 0.5; method-family-conflict warning lists the offending pair.

### Task 17 — FastAPI app + read-only routes

**Files:**
- Create `src/strata/api/app.py` — FastAPI app, mount routers, OpenAPI tag metadata.
- Create `src/strata/api/concept.py` — `GET /c/{slug}` returns `{concept, measurements, disagreement, used_in_frameworks, used_in_tams, annotations}`. Shape maps 1:1 to design's concept page (`docs/design/component-catalog.md`).
- Create `src/strata/api/primitive.py` — `GET /p/{slug}` returns full primitive + source + lineage + annotations + revision history (single-entry list for v0.2).
- Create `src/strata/api/framework.py` — `GET /f/{slug}` returns framework + variants + applicability + sample TAMs.
- Create `src/strata/api/build.py` — `POST /mint` accepts a `BuildState`, returns `{hash, url}`. `GET /build/{hash}` returns the workhorse-view payload (target, frameworks, scenarios, independence, banners). For v0.2 the state is held in memory only; persistence is v0.3.
- Create `src/strata/api/tam.py` — `GET /tam/{hash}` returns the frozen artifact shape.
- Wire `strata serve` in `cli.py` (`uvicorn strata.api.app:app --port 8000`).

**Verify:** httpx client tests in `tests/api/` for each route against the P&C seed data.

## What's deferred (explicit non-goals for v0.2)

- **Frontend** — graph renderer, hover preview, red-dot annotation UI. v0.3.
- **LLM query parser** — Surface 2 (interpretation cards). v0.3 with vendor-flexible plumbing.
- **Search index** — full-text, tag-faceted, semantic. v0.3 (text) and v1.0 (semantic).
- **Postgres mirror** — YAML-from-git is enough at v0.2 volume.
- **Auth** — required for `is_promoted`, rate-limiting. v0.5.
- **Contribution flow** — PR templates, annotation web form, LLM PR review. v0.5.
- **Public registry** — `/browse` route. v1.0.
- **Source snapshot blob store** — URL-only at v0.2; content-addressed blob storage when blob count justifies it.
- **Sensitivity-aware change detection** (Q5) — requires source-polling infra. v0.3 or later.

## Verification scenario (the unit-test of the schema)

End of v0.2 is "done" when **all** of these pass:

1. `uv run pytest` — green.
2. `uv run pyright src/ tests/` — `0 errors, 0 warnings`.
3. `uv run strata validate data/` — exit 0 on the seeded P&C scenario.
4. `uv run strata serve` then `curl http://localhost:8000/c/pc-doc-gen-tam-us` returns a JSON shape including: concept definition, list of measurements with source-tier badges, three frameworks linked, the seeded annotation surfaced.
5. `curl http://localhost:8000/build/{hash}` returns the workhorse-view shape for the P&C target with all three scenarios computed and an independence score > 0.5.
6. The schema accommodates the P&C scenario **without** any "just one exception" patches. If a real edge case forces a model change, document it as a follow-up Q39+ in `docs/07-data-layer-brainstorm.md` and bump `schema_version`.

## Open questions (resolve as they come up, don't pre-decide)

- **Formula DSL precision.** Start with a safe-AST `+ - * /` over named bindings. If a framework needs `min`, `max`, `clip`, `weighted_avg`, add them explicitly — don't reach for `eval`. (Q15 already prohibits scalar defaults; this is the same spirit applied to formulas.)
- **YAML extras** — should we allow unknown keys for forward-compat or reject them? Default: reject (strict Pydantic). Easier to relax than tighten.
- **Date handling** — `as_of` as `date` or `datetime`? Start `datetime` UTC; downgrade to `date` if it never matters at sub-day resolution.
- **Annotation moderation stub** — v0.2 ships with no moderation, annotations load straight from `data/annotations/`. v0.5 wires the queue.
